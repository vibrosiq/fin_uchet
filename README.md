# Finzentra — финансовый учёт для предпринимателей

**Finzentra** — веб-сервис для предпринимателей и самозанятых, которым необходимо вести финансовый учёт нескольких направлений деятельности в одном приложении.

Проект помогает разделять доходы и расходы по проектам, контролировать финансовые операции и анализировать результаты деятельности за выбранные периоды.

## О проекте

Предприниматели, ведущие несколько направлений бизнеса, могут сталкиваться со смешением финансовых потоков и сложностями при определении прибыльности каждого направления.

Finzentra разрабатывается как простой инструмент для ведения раздельного финансового учёта и получения наглядной информации о состоянии бизнеса.

## Основные возможности

### Финансовый учёт
- Добавление, редактирование и удаление доходов и расходов.
- Разделение операций по проектам.
- Категоризация финансовых операций.
- Учёт налоговых платежей.
- Указание фактической даты операции и периода, к которому она относится.
- Фильтрация операций по проектам и периодам.

### Финансовая аналитика
- Cash Flow — анализ движения денежных средств по датам фактических операций.
- P&L — анализ доходов и расходов за соответствующие учётные периоды.
- Расчёт финансовых показателей.
- Сравнение результатов за разные периоды.

### Пользовательский интерфейс
- Адаптивный интерфейс для компьютеров и мобильных устройств.
- Разделы проектов, операций и настроек.
- Сохранение финансовых данных в браузере.
- Поддержка PWA — возможность установки приложения на устройство.

### Авторизация
- Регистрация по электронной почте или номеру телефона.
- Вход в аккаунт.
- Хеширование паролей.
- Выдача JWT-токена для авторизованного пользователя.

## Архитектура проекта

Проект разделён на клиентскую и серверную части.

- **Frontend** отвечает за отображение интерфейса, работу с финансовыми операциями и формирование аналитических отчётов.
- **Backend** реализует серверную часть регистрации и авторизации пользователей.
- **PostgreSQL** используется для хранения учётных записей пользователей.

В текущей версии финансовые операции, проекты и категории сохраняются в браузере с помощью `localStorage`. Их полноценное хранение и обработка через серверную базу данных относятся к дальнейшему развитию проекта.

## Установка и запуск

### Требования

- Python 3.10 или выше.
- Node.js и npm.
- PostgreSQL.

### 1. Клонирование репозитория

```bash
git clone https://github.com/finuchet2/fin_uchet.git
cd fin_uchet
```

### 2. Настройка Backend

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его:

```bash
# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
pip install email-validator
```

Создайте в корне проекта файл `.env`:

```env
DATABASE_URL=postgresql+psycopg2://postgres:your_password@localhost:5432/postgres

SECRET_KEY=your_secret_key
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
```

Замените `your_password` на пароль пользователя PostgreSQL, а `your_secret_key` — на собственный секретный ключ.

Убедитесь, что PostgreSQL запущен и указанная база данных существует.

Запустите сервер из корневой папки проекта:

```bash
uvicorn app.main:app --reload --port 8000
```

После запуска:
- API: http://localhost:8000
- Интерактивная документация API: http://localhost:8000/docs

### 3. Настройка Frontend

Откройте отдельный терминал и перейдите в папку frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Создайте файл `.env.local` в папке `frontend`:

```env
VITE_API_URL=http://localhost:8000
```

Запустите frontend:

```bash
npm run dev
```

Откройте адрес, указанный Vite в терминале (обычно http://localhost:5173).

### 4. Сборка Frontend

Для создания production-сборки выполните:

```bash
npm run build
```

Для локального просмотра собранной версии:

```bash
npm run preview
```

## Разработка и проверка

В папке `frontend` доступны команды:

```bash
npm run typecheck
npm run lint
npm run build
```

- `typecheck` — проверка типов TypeScript.
- `lint` — проверка кода ESLint.
- `build` — сборка приложения.
